## What the checks establish

- [Web player tests](web-player-tests.log): seven groups run the actual JavaScript
  extracted from `PlayerView.swift`. Advancing `readyState=2` video clears false
  buffering; a real stall still reports it. Pause preserves user intent. Nested
  pause advertisements and unmarked close/continue buttons are hidden while
  captions survive. Duration-matched VOD behind a blob can be handed to native;
  unrelated manifests, preroll media and sealed-loader sources are not promoted.
  WebKit PiP command/background dispatch and unsupported capability reporting pass.
- [Pine provider tests](pine-provider-tests.log): 143 existing assertions pass on
  production model/provider code with controlled responses; these are not live
  PineDrama playback observations.
- [Media cache tests](media-cache-tests.log): 18 assertions pass using the actual
  Foundation actor and a loopback HTTP server. Both five- and ten-file windows
  finish, concurrent resolutions coalesce, reverse navigation returns the exact
  previous file, cleanup preserves the current file, cancellation can recover,
  and failures do not spin. HTML and incomplete oversized MP4 responses are rejected.
- [Server observations](media-cache-fixture-stats.json) independently record ten
  complete movie transfers by clip ID. The 25 MiB fixture receives a bounded
  24 MiB range, which is rejected as incomplete. Test videos are generated by
  FFmpeg; no original movie media, signed URLs or account sessions are committed.
- All application Swift sources and `AIDramaUITests.swift` parse. Models and cache
  typecheck with Swift 6.0.3 in Swift 5 mode. Python fixture compilation, shell
  syntax and `git diff --check` pass. UIKit/AVKit/SwiftUI were not typechecked by
  this Linux compiler.

## Source protection and limits

[Source preservation](source-preservation.json) compares nine protected
provider/catalog/parser/transport files byte-for-byte with `a785d35`. All remain
identical. The normal mpv option map is identical to the preceding release.
Shared WebKit state/presentation, PiP readiness and player settings changes are
authorized by the current user request.

AI prefetch requests five clips by default or ten in settings, with two downloads,
24 MiB per file and 256 MiB total. It retains three previous files and one silent
warm decoder (3 seconds/12 MiB). Oversized, non-MP4 and failed downloads retain
normal network playback; instant playback is not guaranteed on every live clip.
Source-2 resolver, gateway protocol and MKV buffering defaults were not retuned
without a usable playback measurement.
